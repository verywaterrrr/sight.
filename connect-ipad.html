Practice on your iPad

Keep your iPad and this computer on the same Wi-Fi. The computer processes scores; singing stays on your iPad.

Microphone access needs a trusted HTTPS connection. This is a one-time local development setup.

  1. On the computer, keep npm run dev running, then start npm run dev:https in a second terminal.
  2. Open the printed “iPad setup” address in iPad Safari. Download the Sight certificate profile generated by your computer.
  3. In Settings, open Profile Downloaded (or General → VPN & Device Management), review the Sight local development profile, and install it.
  4. Go to Settings → General → About → Certificate Trust Settings and enable trust for Sight Local Development.
  5. Open the secure practice page, choose Monitor, and tap Start monitoring. Allow microphone access.

Install only the profile generated by your own computer. The local certificate keys stay inside this project. No system certificate is installed automatically. Remove this development profile from Settings when you no longer need it. HTTP and HTTPS have separate saved-score libraries.

If Wi-Fi changes the computer's address, restart the HTTPS server and use the new printed link. Physical iPad audio behaviour still needs testing.

Certificate trust instructions: Apple Support.
